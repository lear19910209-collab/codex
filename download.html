在 iPad 上下载和交付

  1. 用 Safari 打开当前下载页面，点击上面的“下载 HTML 文件”。
  2. 如果 Safari 提示是否下载，请确认下载。
  3. 在 Safari 的下载入口或“文件”App 中找到文件。
  4. 将文件上传到百度网盘，再发送分享链接。

电脑买家怎么使用

  1. 将收到的 HTML 文件保存到电脑的固定文件夹。
  2. 用最新版 Chrome 或 Edge 浏览器打开。
  3. 点击软件里的“使用说明”查看教程，处理订单后记得导出备份。
