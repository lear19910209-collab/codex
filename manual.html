1. 软件能做什么

小单用来记录客户订单，并自动计算商品金额、订单总价、定金、尾款、成本和利润。你可以维护常用价格、查老客户报价、生成给客户看的报价单，并导出账目和数据备份。

软件有五个主要页面：

页面名称主要用途
工作台查看当天订单、未收款项、已完成订单和利润
订单记录搜索、筛选、查看、修改和删除订单
商品 / 服务价格库保存常用项目的名称、默认售价、默认成本和内部备注
客户历史按客户昵称查看过去订单和当时的价格
备份与导出下载订单 CSV、导出全部数据、导入备份恢复

不需要在软件里注册账号，也不需要登录 GitHub。买家使用的是上面的软件网页，不是 GitHub 的代码仓库页面。

先了解数据保存方式：订单保存在当前设备、当前浏览器的本地存储中，不会上传到卖家的数据库，也不会自动同步到另一台设备。关闭软件后可以继续使用，但请定期下载备份文件。

2. 第一次使用：五分钟上手

第一次建议按这个顺序操作：

  1. 用浏览器打开软件网址。iPad 用户先按第 3 节添加到主屏幕。
  2. 打开“商品 / 服务价格库”，点击“添加商品 / 服务”。
  3. 新增“头像定制”：默认售价填 99，默认单位成本填 20，点击“保存项目”。
  4. 点击“新建订单”，客户昵称填“练习客户”，从价格库选择“头像定制”。
  5. 数量填 1，定金比例填 30，其他金额保持 0。此时总价为 99.00 元，定金为 29.70 元，尾款为 69.30 元，预计利润为 79.00 元。
  6. 点击“保存订单”。看到“订单已保存”提示后，进入“订单记录”查看。
  7. 打开“详情”，点击“生成报价单”，试着保存一张图片。
  8. 打开“备份与导出”，点击“导出备份文件”，确认能在设备中找到下载文件。

练习完成后可以删除练习订单。正式开始接单时，填写真实客户昵称、价格和实际成本。

注意：表单下方显示了计算结果，不代表订单已经保存；请点击“保存订单”或“保存修改”。

3. iPad 怎么打开、添加到主屏幕

3.1 在 Safari 打开软件

  1. 打开 iPad 的 Safari 浏览器。
  2. 在地址栏输入或粘贴软件网址：https://lear19910209-collab.github.io/codex/。
  3. 等待“小单”首页正常显示。首次打开需要联网。
  4. 确认页面有“工作台”“订单记录”“商品 / 服务价格库”等入口。

建议使用 Safari 的普通浏览模式。微信、聊天 App 内置网页窗口或文件预览器可能有不同的保存、下载限制。

3.2 添加到主屏幕

  1. 在 Safari 点“分享”按钮，图标通常为方框加向上的箭头。
  2. 在菜单中找到“添加到主屏幕”。没有立即看到时，可向下滚动菜单。
  3. 名称保留“小单”，点击“添加”。
  4. 返回 iPad 主屏幕，找到“小单”图标。
  5. 从图标打开软件，再开始录入正式订单。

以后可以直接点击主屏幕图标进入，不需要每次查找网址，也不需要下载压缩包、解压或使用电脑部署。

如果找不到“添加到主屏幕”，请先确认正在 Safari 中打开完整的软件网页，而不是打开一个下载的 HTML 文件或代码页面。不同 iPadOS 版本的菜单位置可能略有不同。

3.3 离线使用

软件首次联网打开后，会尝试保存运行所需的网页文件。等待页面加载完成，建议先关闭并重新打开一次，再测试断网使用。

缓存准备完成且没有被系统清理时，断网仍可记录订单、计算金额、查看已存数据和生成报价图片。首次访问、重新缓存或获取新版本需要网络。网页缓存与订单数据是两回事，缓存不是数据备份。

3.4 固定一个使用入口

建议正式使用时固定从主屏幕“小单”图标打开。某些 iPadOS 版本中，Safari 标签页与主屏幕应用可能使用独立存储。如果切换入口后看不到旧订单，先回到原入口检查，导出备份后再到新入口恢复，详见第 15 节。

4. 电脑、手机怎么使用

4.1 电脑通过网址使用

  1. 使用最新版 Chrome 或 Edge 打开软件网址。
  2. 将网址收藏到书签，日后使用同一浏览器、同一用户配置打开。
  3. 不需要安装开发工具，不需要购买 API。

通过网址进入软件不需要登录 GitHub。不同设备的订单数据不会因为打开同一个网址就自动共享。

4.2 电脑通过文件离线使用

如果交付方提供单独的 index.html 文件：

  1. 把文件保存到电脑上的固定文件夹。
  2. 双击文件，或右键“打开方式”，选择 Chrome 或 Edge。
  3. 正常录入订单，无需运行服务器，也无需联网。

如果收到的是压缩包，请先解压，再打开其中的 index.html；也可以请交付方直接发送单独的 HTML 文件。

本地文件版本与网页版本属于不同的使用入口，数据不会自动互通。移动文件、重命名文件、换浏览器前，请先备份。

4.3 手机使用

手机可用完整浏览器打开软件网址，界面会适应窄屏。订单表格较宽时，左右滑动表格可查看后面的金额和操作按钮。

手机、平板的本地文件预览器不一定支持完整运行和存储，因此移动设备优先使用网址入口。不同浏览器的下载、分享和打印步骤可能不同。

5. 认识首页和五项统计

首页“工作台”展示五项统计，以及最近六笔订单。

统计名称实际统计范围怎么理解
今日新增订单按设备本机日期统计今天创建的订单，包括今天新增后又取消的订单今天记了多少笔单，不代表今天完成或收款的数量
待收款金额未完成、未取消订单的剩余应收合计还有多少钱需要向客户收取
待收尾款金额已付定金、制作中、待收尾款订单的尾款合计已收到约定定金后，还需收取多少尾款
已完成订单数当前状态为“已完成”的订单数量已按完成状态记录的订单数量
总利润当前所有“已完成”订单的利润合计完成订单的累计计算利润，不是所有在做订单的预计利润

“待收尾款金额”已经包含在“待收款金额”里，两项不要相加。

例：订单总价为 324 元，定金为 97.20 元，尾款为 226.80 元：

  • 待付款时，待收款金额计入 324 元，待收尾款金额不计入这笔订单。
  • 更新为已付定金后，两项分别计入 226.80 元和 226.80 元。
  • 更新为已完成后，两项都不再计入这笔订单，总利润开始计入这笔订单的利润。
  • 更新为已取消后，这笔订单不计入应收、尾款和总利润。

修改订单金额、修改状态、删除订单或恢复备份后，首页统计会同步重新计算。

6. 建立商品 / 服务价格库

6.1 添加常用项目

  1. 打开“商品 / 服务价格库”。
  2. 点击“添加商品 / 服务”。
  3. 填写名称、默认售价、默认单位成本和备注。
  4. 点击“保存项目”。
填写项含义示例
名称你出售的商品或服务项目头像定制
默认售价一个单位向客户收取的价格99 元 / 件
默认单位成本完成一个单位需要承担的商品或服务成本20 元 / 件
备注价格库内部说明基础款，包含两次修改

价格库备注是内部说明，不会自动复制进订单，也不会自动显示在客户报价单上。

6.2 用价格库项目开单

可以在项目卡片上点击“用这个项目开单”，也可以在“新建订单”中使用“从价格库选择”。名称、单价和单位成本会自动填入，其他金额仍由你填写。

带入后可以改价。例如默认售价 99 元，给某个客户报价 89 元，只需修改该订单的单价，不会改变价格库，也不会改变其他订单。

6.3 搜索、编辑和删除项目

  • 使用价格库上方的搜索框，按项目名称查找。
  • 点击卡片上的“编辑”，修改后点击“保存项目”。
  • 点击“删除”，阅读确认提示后确认删除。

修改或删除价格库项目，已有订单的名称、单价、成本和历史报价仍然保留。价格库不是库存系统，不会自动扣减数量。

7. 新建订单：每个填写项的含义

在“工作台”“订单记录”或“客户历史”等页面点击“新建订单”，按以下三组信息填写。

7.1 客户信息

填写项是否必填填写方法
客户昵称是使用你能辨认的昵称，例如“小林 · 微信”
联系方式否可填写微信号、手机号或其他联络方式，留空也能保存

相同客户尽量使用完全一致的昵称。昵称不同会分成不同的历史客户；不同客户如果昵称相同，也会归到一起。可用平台或识别后缀区分重名客户。

联系方式仅用于自己查看和账目导出，不显示在生成的客户报价单上。

7.2 商品 / 服务

填写项填写方法注意事项
从价格库选择可选一个常用项目，也可保留自定义不选择价格库也能开单
项目名称填写订单内容，例如“头像定制”必填，会显示在客户报价单上
数量填写整数，例如 1、2、3按件计，当前不支持 1.5 等小数数量
单价一个单位的售价，例如 99填数字，不要输入“元”或货币符号
单位成本一个单位的成本，例如 20软件会按数量相乘，不要误填整笔商品总成本
运费整笔订单的运费，例如 12当前版同时作为向客户收取的运费和自己的运费成本

第一版每笔订单只有一个商品 / 服务项目字段。不同项目需要分别开单，不能在一笔订单中逐行添加多个项目并分别定价。

7.3 费用与收款

填写项含义示例
加急费向客户收取的加急费用20 元
其他费用向客户收取的其他收费包装服务费 5 元
优惠金额从整笔订单中减掉的优惠减 10 元，填写 10，不填写 −10
其他成本自己承担的额外成本外包、材料等未计入单位成本的支出 7 元
定金比例约定先收取总价的百分之多少30% 填 30，不填 0.3
订单状态当前的收款或制作阶段新客户尚未付款时选“待付款”
备注客户可以看到的订单说明交付日期、修改次数、约定范围

没有某项费用时填 0，不要留空。金额最多两位小数，按人民币计算。

“其他费用”增加客户应付金额，“其他成本”减少你的利润，二者不是一回事。

订单备注会显示在报价单上，避免在这里填写内部成本、利润、私人评价等不希望客户看到的内容。需要记录这类内部信息时，本版本没有单独的私密备注栏。

7.4 查看结果并保存

填写时，下方会实时显示订单总价、应收定金、应收尾款、预计利润、商品金额和总成本。

确认客户、名称、数量、费用、比例和状态都正确后，点击“保存订单”。出现“订单已保存”提示，才表示本地写入完成。

关闭表单时，如果填写内容未保存，软件会提示是否放弃修改。点击取消会保留表单；确认放弃则关闭并丢弃未保存内容。

8. 自动计算规则与完整示例

8.1 七个计算公式

项目计算公式
商品金额数量 × 单价
订单总价商品金额 + 运费 + 加急费 + 其他费用 − 优惠金额
定金订单总价 × 定金比例，四舍五入到分
尾款订单总价 − 定金
商品成本数量 × 单位成本
总成本商品成本 + 运费 + 其他成本
利润订单总价 − 总成本

软件内部以整数“分”计算。尾款由总价减定金得到，因此定金与尾款相加始终等于总价。定金比例可以为 0% 或 100%；分别表示不收定金或先收全款。

8.2 一笔完整示例

客户“小林 · 微信”订购 3 件头像定制，填写如下：

填写项数值
数量3
单价99 元
单位成本20 元
运费12 元
加急费20 元
其他费用5 元
优惠金额10 元
其他成本7 元
定金比例30%

软件自动得出：

结果计算过程金额
商品金额3 × 99297.00 元
订单总价297 + 12 + 20 + 5 − 10324.00 元
定金324 × 30%97.20 元
尾款324 − 97.20226.80 元
商品成本3 × 2060.00 元
总成本60 + 12 + 779.00 元
利润324 − 79245.00 元

收到 97.20 元定金后，将状态改为“已付定金”。收到 226.80 元尾款且订单交付完成后，将状态改为“已完成”。

8.3 运费和成本的口径

当前版“运费”只有一个金额，同时加进客户总价并加进自己的成本，适合收取运费与实际支出一致的场景。

如果你给客户包邮，可以把“运费”填 0，将自己承担的实际寄件支出计入“其他成本”。例如实际寄件费 12 元，可以把其他成本增加 12 元。

如果向客户收取的运费与实际支付运费不同，当前版没有两个独立的运费栏，不能单独准确核算这部分运费差额。请根据实际情况核对账目，不把这一版的估算结果直接当作完整财务报表。

加急费若还带来额外支出，需要另外填入“其他成本”。不要把同一笔成本同时填入单位成本和其他成本，以免重复扣除。

8.4 优惠、零金额和亏损

  • 优惠为正数，软件负责扣除；优惠不能超过优惠前订单金额。
  • 单价和各项费用可以填 0；完全抵扣后总价可以为 0。
  • 成本高于总价时，利润会显示负数，代表按当前输入计算的亏损。
  • 修改已收定金订单的金额或比例，会重算“应收定金”和“应收尾款”，软件不会保留此前实收款金额。遇到客户已经实际支付旧定金的情况，请先核对实际款项，当前版不能独立记录调整后的实收差额。

9. 订单状态与收款管理

9.1 六种状态的含义

状态软件采用的收款假设待收款如何计入是否计入首页总利润
待付款尚未收到付款整笔订单总价否
已付定金已收到约定的定金尾款否
制作中默认已收到约定的定金尾款否
待收尾款默认已收到约定的定金尾款否
已完成默认已经收全款0是
已取消退出当前应收与利润统计0否

“已完成”不仅影响制作进度，也代表软件认为已经收齐款项。已经制作完成但还没收尾款时，使用“待收尾款”，避免把未到账的钱当作已收款。

“制作中”默认已收定金。如果你的订单实际未收定金，不要仅为了标记开始制作就选这个状态，否则首页会少计待收款项。第一版将制作与收款合并为一套状态，无法独立标记“未收定金但制作中”。

9.2 修改订单状态

  1. 在“订单记录”找到订单，点击“详情”。
  2. 在“更新状态”的下拉菜单选择新的状态。
  3. 点击“保存状态”。仅选择状态但未点击保存，不算更新完成。
  4. 返回首页查看变化。

在“修改订单”表单中也可选择状态，再点击“保存修改”。状态不强制按顺序流转，选错后可以修改回来。

9.3 推荐的正常流程

待付款 → 已付定金 → 制作中 → 待收尾款 → 已完成。

不收定金的订单，可以根据实际收款情况调整流程；由于制作中仍按“已收到约定定金”处理，定金比例为 0% 时，制作中的剩余应收依然是全部总价。

取消订单建议保留记录并设为“已取消”，便于将来查询沟通历史。软件不会执行退款，也不会跟踪已取消订单的定金保留、退款或损失。

10. 查找、修改、删除订单

10.1 搜索订单

  1. 打开“订单记录”。
  2. 在搜索框中输入客户昵称、项目名称或订单备注里的关键词。
  3. 列表会随输入变化，只显示匹配的订单。
  4. 清空关键词，或使用无匹配结果页面的“清空筛选”，恢复查看。

当前订单搜索不按联系方式、金额或日期查询。

10.2 按状态筛选

在“全部状态”下拉菜单中选择待付款、制作中等状态。可以同时使用关键词和状态筛选。

例如搜索“小林”，再选“待收尾款”，就能查看这个昵称下等待收尾款的订单。

10.3 查看订单详情

点击订单右侧“详情”，查看客户、联系方式、商品数量、单价、各项费用、定金尾款、成本和利润。

详情窗口含内部成本与利润，给客户看时请使用“生成报价单”，不要直接发送详情窗口截图。

10.4 修改订单

  1. 打开订单详情，点击“修改订单”。
  2. 调整客户、项目、数量、金额、状态或备注。
  3. 核对下方实时计算结果。
  4. 点击“保存修改”。

修改后，订单记录、客户历史和首页统计都会同步更新。订单的创建日期保持不变，更新日期会变化。

如果改了客户昵称，订单会按新昵称重新归入客户历史。旧客户分组中没有其他订单时，会从客户历史列表中消失。

已发给客户的图片或 PDF 不会自动更新；改价后请重新生成报价单，再通知客户以哪份为准。

10.5 删除订单

  1. 打开订单详情，点击“删除订单”。
  2. 阅读确认提示，确认需要删除后点击“删除订单”。
  3. 订单会从列表和客户历史中移除，统计也会重新计算。

删除没有回收站或单笔撤销按钮。需要找回时，只能使用包含该订单的旧备份恢复全部数据；旧备份会覆盖当前数据，所以删除前建议先导出备份。

11. 老客户再次下单与历史报价

11.1 查看客户以前的价格

  1. 打开“客户历史”。
  2. 在搜索框中输入客户昵称或昵称的一部分。
  3. 找到客户分组，查看历次下单日期、商品 / 服务、历史单价、数量、总价、优惠和状态。
  4. 点击某笔订单的“详情”，查看完整内容；也可点击“报价单”生成该笔订单当前保存的报价。

历史列表包含已取消订单。它反映目前保存的订单内容，不是不可更改的历史版本存档；编辑旧订单后，历史展示也会变化。

11.2 再次开单

在客户分组右侧点击“再次开单”，软件会带入客户昵称和联系方式。

“再次开单”不会自动复制上一次的项目、价格和费用。你需要选择价格库或填写新的订单内容，再参考历史报价决定是否沿用老价格。

新建订单时，如果填写的昵称与旧订单完全一致，表单会提示已有历史订单和最近报价，便于核对。

12. 生成、保存、发送报价单

12.1 打开报价单

先保存订单，再使用以下任一入口：

  • 订单列表右侧点击“报价单”。
  • 订单详情点击“生成报价单”。

报价单是专门给客户看的页面，包含客户昵称、项目名称、数量、单价、商品金额、优惠、运费、加急费、其他费用、总价、定金、尾款、备注、报价日期和编号。

不会单独显示单位成本、其他成本、总成本、利润、联系方式、内部价格库备注或订单状态。但你主动写进订单备注的内容会显示，因此发送前仍需检查。

报价单显示“报价日期”，当前取自订单创建日期；修改订单后不会自动变成修改当天的日期。编号用于识别订单，不是发票编号。报价单展示约定金额，不是付款凭证。

12.2 保存图片

  1. 在报价单顶部点击“保存图片”。
  2. 等待生成完成，浏览器会下载 PNG 图片。
  3. 电脑在下载文件夹中查找以“小单报价”开头的 .png 文件。
  4. iPad 可在 Safari 的下载入口或“文件”App 中查找下载文件；保存位置取决于 Safari 下载设置。
  5. 打开图片，核对金额和备注后，通过微信等平台发送给客户。

iPad 如需保存到“照片”，可以打开图片后点系统“分享”，在系统提供该选项时选择“存储图像”。保存图片按钮通常是下载文件，不等于自动进入相册。

12.3 打印或导出 PDF

电脑操作：

  1. 点击“打印 / 导出 PDF”。
  2. 在浏览器打印窗口中，目标选择“另存为 PDF”或系统提供的 PDF 保存选项。
  3. 建议关闭“页眉和页脚”，避免输出网页地址或本地文件路径。
  4. 查看预览，选择保存位置，点击保存。需要纸质报价时选择打印机。

iPad 操作：

  1. 点击“打印 / 导出 PDF”，打开系统打印界面。
  2. 需要实体打印时，选择支持的打印机。
  3. 如果系统允许，可展开打印预览页面，再通过“分享”保存到“文件”或发送 PDF。
  4. iPadOS 版本和打印界面可能不同；没有找到 PDF 保存入口时，优先使用“保存图片”发送报价。

特别长的备注可能不适合单张图片，软件会提示改用打印 / PDF。

12.4 一段可复制的客户消息

你好，这是本次订单的报价单。总价 324 元，定金 97.20 元，尾款 226.80 元。项目范围和交付说明见图片备注，请确认后回复我。

这段是第 8 节示例消息，实际发送时按你自己的订单金额调整。软件不代收款、不检测到账，也不会自动把消息发给客户。

13. 导出订单 CSV，用 Excel 查看

13.1 导出方法

  1. 打开“备份与导出”。
  2. 找到“订单导出到 Excel”，点击“导出订单 CSV”。
  3. 在下载位置找到以“小单全部订单”开头的 .csv 文件。
  4. 用 Excel、WPS 或支持 CSV 的表格工具打开。

导出包含全部订单，包括已完成和已取消订单，不受订单页面当前搜索或状态筛选影响。

主要列包括：订单编号、创建时间、客户昵称、联系方式、项目名称、状态、数量、单价、单位成本、商品金额、运费、加急费、其他费用、其他成本、优惠、定金比例、总价、定金、尾款、总成本、利润和备注。

CSV 中每笔订单的利润是计算值，包括未完成和已取消订单；如果要与首页总利润一致，需在表格中筛选“已完成”后求和。CSV 的定金和尾款列是约定金额，不是银行流水或实际已收金额。

13.2 Excel 中文或分列不正常怎么办

文件已使用适合中文的 UTF-8 编码。如果双击打开后乱码或全部内容挤在一列：

  1. 在 Excel 选择“数据 → 从文本 / CSV”，或对应版本的导入菜单。
  2. 选择导出的文件。
  3. 编码选择 UTF-8，分隔符选择逗号。
  4. 查看预览正常后导入。

部分联系方式、昵称如果以加号等字符开头，可能出现文本保护前缀，这是防止表格把文本当公式执行。用于阅读账目即可。

CSV 含联系方式、成本和利润，请自行保管；给客户发报价请使用报价图片或 PDF。CSV 不能导回软件恢复订单，恢复要用 JSON 备份。

14. 备份全部数据与恢复

14.1 为什么需要备份

订单保存在浏览器，不是保存在软件 HTML 文件或 GitHub 仓库里。重新下载软件、重新打开网址、重新登录 GitHub，都不能从网上找回已经丢失的本地订单。

清理网站数据、换设备、换浏览器、卸载浏览器、部分系统存储清理等，可能让本地数据消失。建议每次处理完订单后导出一次备份，重要修改和删除前也先备份。

14.2 导出全部数据

  1. 打开“备份与导出”。
  2. 点击“导出备份文件”。
  3. 等待下载完成，找到以“小单数据备份”开头、后缀为 .json 的文件。
  4. 把它保存到安全位置，并确认文件实际存在。

电脑可存到专用备份文件夹、移动硬盘或自己选择的网盘。iPad 可使用“文件”App，在“下载项”中找到文件，再移动到便于查找的文件夹或 iCloud 云盘。使用 iCloud 等同步的是你手动导出的备份文件，不代表软件会自动同步订单。

JSON 备份包含全部订单和价格库，也包含客户联系方式、成本和利润。可以按“日期 + 记录用途”整理备份，保留多个版本，例如“接单备份 / 2026-10-07 收工后”。不需要修改文件内容，也不需要学习 JSON。

软件显示“上次导出”时间，只表示进行过导出操作；请另外确认下载完成并放在可找回的位置。

14.3 导入备份恢复

  1. 如果当前设备已经有订单，先导出一份当前数据备份。
  2. 点击“选择备份文件”。
  3. 在电脑或 iPad 文件选择器中，选中之前导出的 .json 文件。
  4. 软件会检查文件，并显示将导入的订单、价格库数量。
  5. 核对数量和文件来源，点击“确认恢复”。
  6. 看到“备份已恢复”提示后，到订单、价格库和首页检查结果。

导入是整体替换，不是追加或合并。例如当前有 10 笔订单，旧备份只有 8 笔，恢复后会变成旧备份里的 8 笔，当前多出的两笔不会自动保留。

若按“取消”，不替换当前数据。不是本软件备份、文件损坏或数据字段不正确时，软件会拒绝导入，原数据不会被替换。

14.4 导入前的恢复副本

如果浏览器已有保存的数据，导入前会在本地保留一份原数据恢复副本。在“备份与导出”中可下载“上一次导入前的恢复副本”。

选错备份并完成恢复后，可以下载这个副本，再把副本导入恢复。恢复前先导出当前状态，便于保留两份数据。

恢复副本只保留最近一次导入前的数据，下一次导入可能覆盖它；它也保存在浏览器中，清理网站数据时可能一起丢失。因此它不能代替你独立下载并保管的备份文件。

15. 换设备、换浏览器、换使用入口

迁移的基本步骤始终是：旧入口导出备份 → 保存或传输 JSON 文件 → 新入口导入备份。

15.1 从 iPad 换到电脑

  1. 在 iPad 旧入口导出 JSON 备份。
  2. 通过自己的文件同步、邮件或传输工具，将文件送到电脑。
  3. 在电脑浏览器打开软件网址。
  4. 打开“备份与导出”，导入 JSON 文件。

15.2 从 Safari 切换到主屏幕图标

  1. 在 Safari 里仍能看到旧订单时，先导出备份。
  2. 添加到主屏幕，从图标打开软件。
  3. 如果订单没有自动出现，导入刚才的备份。
  4. 后续固定从图标打开，减少入口混用。

15.3 从电脑文件版切换到网页版本

先在原来的 index.html 中导出，再到网页版本导入。不能仅把 HTML 文件传给另一台电脑就搬走订单；HTML 是软件程序，JSON 才是你的数据备份。

15.4 多台设备同时接单

第一版不会自动合并多设备数据。两台设备分别新增订单后，直接拿一台的备份覆盖另一台，可能丢掉另一台新增的记录。

建议指定一台设备作为主要记账设备。需要换设备时，先停止旧设备录入、迁移完整备份，再从新设备继续，避免把它当成共享云账本使用。

16. 日常接单操作清单

接到新订单时

  1. 查客户历史，参考以前的项目和价格。
  2. 新建订单，确认数量、单价、成本、优惠和定金比例。
  3. 保存订单，生成报价单并发送给客户。
  4. 与客户确认范围、交付要求和付款方式。

收到定金后

  1. 在实际收款平台确认到账。
  2. 打开订单详情，把状态改成“已付定金”，点击“保存状态”。
  3. 开始制作后按需要更新为“制作中”。

准备交付时

  1. 查看订单详情中的应收尾款。
  2. 按实际交付和收款安排，更新为“待收尾款”。
  3. 如果修改了价格，重新生成报价单，让客户确认新金额。

收齐款项并完成订单后

  1. 更新为“已完成”。
  2. 查看首页已完成订单数和总利润。
  3. 核对成本是否按实际输入，避免成本为 0 导致利润虚高。

每天收工前

  1. 查看“待付款”和“待收尾款”等未完成订单。
  2. 核对状态与真实到账情况。
  3. 导出一份全部数据备份，确认下载文件可找回。

17. 常见问题与处理方法

Q1：打开链接显示 404

先核对使用的是软件网址：https://lear19910209-collab.github.io/codex/。带有 github.com、tree 或 blob 的地址通常是代码页面，不是软件入口。

软件网页不需要 GitHub 登录。正确网址仍返回 404 时，可能是网页发布配置或托管状态变化，请把网址和错误页面信息告诉软件提供方；不用为此输入账号密码到软件里。

Q2：软件保存后，刷新还有；换入口却没有订单

检查是否换了设备、浏览器、用户配置、无痕窗口、本地文件位置，或从 Safari 切换到主屏幕图标。先回原入口查找；找到后导出 JSON，再到新入口导入。

Q3：没有点保存就关闭表单，能找回吗

未保存表单没有作为订单写入。确认“放弃修改”后，需要重新填写。请先点击保存，再关闭。

Q4：软件提示本地保存失败

可能是浏览器禁用了存储或存储空间不足。失败时不要认为新订单已经写入，也不要立即清理网站数据。先导出现有数据备份，再排查浏览器模式、设备空间或用其他普通浏览器恢复备份。

Q5：软件提示本地数据损坏

请先到“备份与导出”保留原始数据文件，再选择有效的 JSON 备份恢复。原始数据文件不一定能直接导入，保留它有助于后续排查。没有可用备份时，本版本没有自动云端找回功能。

Q6：定金或尾款“看起来不对”

确认定金比例填写的是 30 而不是 0.3；确认总价已加费用、减优惠。定金四舍五入到分，尾款是总价减定金。查看的是约定金额，不代表系统核验过实际付款。

Q7：利润为什么比预期大或小

检查单位成本是否乘上了数量、其他成本是否重复计入、运费是否按相同收入与支出处理。加急费和其他费用会增加收入，若同时产生额外支出，要填入其他成本。

Q8：新订单已经有利润，首页总利润却没变化

详情显示的是这笔订单的计算利润；首页只累计状态为“已完成”的订单。未完成订单不会计入首页总利润。

Q9：已经制作完，为什么还要用“待收尾款”

“已完成”默认已收全款。制作完但还没收齐钱时，使用“待收尾款”，首页才会继续显示剩余应收。

Q10：取消订单后，之前收的定金去哪了

已取消订单不再计入应收和首页利润。软件没有实际收款流水，也不处理退款或定金留存，请在真实交易记录中另行核对。

Q11：老客户的订单没有归到一起，或者两位客户混在一起

客户按昵称归组，前后昵称不同会分开，重名会合在一起。为不同客户设置稳定、唯一的昵称，例如“小林 · 微信”“小林 · 闲鱼”，并修改对应旧订单的昵称。

Q12：改了价格库，为什么旧订单没跟着改

旧订单保留当时保存的售价和成本，这是正常行为。要调整旧订单，请打开该订单的“修改订单”。

Q13：报价图片下载后在哪里

电脑查看浏览器下载文件夹；iPad 查看 Safari 下载入口及“文件”App 的下载位置。文件名以“小单报价”开头，后缀是 .png。它不一定自动进入照片相册。

Q14：导入后少了订单

恢复会整体替换当前数据，旧备份中的记录可能少于当前记录。查看“上一次导入前的恢复副本”，下载后核对并恢复；不要连续多次导入而没有先保留独立文件。

Q15：能把 CSV 导入恢复吗

不能。CSV 用于表格查看，JSON 备份用于恢复订单和价格库。

Q16：软件提示另一个窗口更新了数据

同一浏览器的另一个标签页可能修改了订单。软件会同步列表，并阻止旧表单覆盖新数据。关闭旧表单，重新打开目标订单后再修改，建议避免多个窗口同时编辑同一笔订单。

Q17：会不会把我的成本发给客户

生成的报价单没有成本、利润和联系方式字段；订单详情、CSV 和 JSON 备份含内部信息。请使用报价单发送，并检查订单备注中是否自己写入了内部内容。
