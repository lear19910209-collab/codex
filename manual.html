小单 · 个人接单报价管家

使用说明书

欢迎使用小单。我们希望用简单的操作，帮助你记录每一笔订单，算清报价、定金、尾款和利润。

本说明书介绍软件的打开方式、接单流程、报价单制作和数据备份方法。

一、打开软件

  1. 从百度网盘下载「小单接单报价管家.html」。
  2. 将文件放到电脑上一个固定的文件夹中。
  3. 双击文件，用浏览器打开。
  4. 如果双击没有打开软件，请右键点击文件，选择“打开方式”，再选择 Chrome 或 Edge 浏览器。

看到软件首页后，即可开始使用。下载完成后，日常使用可以断网操作。

建议一直使用同一个浏览器、同一个文件位置。移动文件、重命名文件或更换浏览器前，请先备份数据。

设备说明：本次交付的 HTML 文件适合电脑浏览器使用。手机、iPad 的文件预览不能保证正常运行和保存订单，不能直接套用上述打开步骤。

二、第一次使用

第一次使用时，建议先添加常用商品或服务，再创建订单。

以“头像定制”为例：

  1. 打开「商品 / 服务价格库」。
  2. 点击「添加商品 / 服务」。
  3. 名称填写“头像定制”，默认售价填写 99，默认单位成本填写 20。
  4. 点击「保存项目」。
  5. 点击「新建订单」，填写客户昵称，选择“头像定制”。
  6. 数量填写 1，定金比例填写 30，其他费用保持 0。
  7. 查看计算结果，确认后点击「保存订单」。

这笔订单的计算结果为：

项目金额
订单总价99.00 元
定金29.70 元
尾款69.30 元
预计利润79.00 元

保存后，可以生成报价单，尝试保存图片，再到「备份与导出」下载一份数据备份。

填写完成后一定要点击保存。看到计算结果，并不代表订单已经保存。

三、首页统计怎么看

首页「工作台」显示五项统计：

统计项目含义
今日新增订单今天创建的订单数量，包括创建后又取消的订单
待收款金额尚未完成、尚未取消的订单中，剩余需要收取的金额
待收尾款金额已付定金、制作中、待收尾款订单的尾款合计
已完成订单数当前状态为“已完成”的订单数量
总利润所有已完成订单的利润合计

待收尾款已经包含在待收款金额中，不要将两项相加。

新订单中的预计利润，不会立即计入首页总利润。将订单设为「已完成」后，才会计入。

修改订单金额、更新状态、删除订单或恢复备份后，首页统计会同步更新。

四、管理商品 / 服务价格库

价格库用于保存常用项目，减少重复填写。

添加项目

打开「商品 / 服务价格库」，点击「添加商品 / 服务」，填写：

  • 名称：商品或服务的名称。
  • 默认售价：一个单位向客户收取的价格。
  • 默认单位成本：完成一个单位需要承担的成本。
  • 备注：自己的内部说明，例如服务范围或材料规格。

填写后点击「保存项目」。

使用项目开单

点击项目上的「用这个项目开单」，或在新建订单时使用「从价格库选择」。

项目名称、单价和单位成本会自动带入。你可以根据实际订单调整价格。

编辑或删除项目

在项目卡片上点击「编辑」或「删除」。

修改或删除价格库项目，不会改变已经保存的订单。旧订单会保留当时的售价和成本。

价格库备注仅供自己查看，不会自动显示在客户报价单上。

五、新建订单

点击「新建订单」，依次填写客户、项目和费用信息。

填写项填写方法
客户昵称填写便于识别的客户名称
联系方式选填，可记录微信号、手机号等
项目名称填写本次订单的商品或服务
数量填写整数，例如 1、2、3
单价填写一个单位的售价
单位成本填写一个单位的成本，软件会自动乘以数量
运费填写整笔订单的运费
加急费填写向客户收取的加急费用
其他费用填写向客户收取的其他收费
优惠金额填写要减去的金额，例如优惠 10 元就填 10
其他成本填写自己承担的额外支出
定金比例收取 30% 定金就填 30
订单状态按实际收款和制作情况选择
备注填写交付日期、修改次数、服务范围等约定

没有某项费用时填写 0。金额最多保留两位小数。

“其他费用”是收入，“其他成本”是支出，请分开填写。

订单备注会显示在客户报价单上，请不要写入成本、利润或其他不希望客户看到的内容。

填写过程中，软件会自动显示总价、定金、尾款和预计利润。核对后点击「保存订单」。

当前每笔订单记录一个项目。不同项目需要分别开单。

六、金额怎么计算

项目计算方式
商品金额数量 × 单价
订单总价商品金额 + 运费 + 加急费 + 其他费用 − 优惠金额
定金订单总价 × 定金比例
尾款订单总价 − 定金
商品成本数量 × 单位成本
总成本商品成本 + 运费 + 其他成本
利润订单总价 − 总成本

定金四舍五入到分，尾款由总价减去定金得到。

完整示例

一笔订单填写：

填写项数值
数量3
单价99 元
单位成本20 元
运费12 元
加急费20 元
其他费用5 元
优惠金额10 元
其他成本7 元
定金比例30%

计算结果：

项目金额
商品金额297.00 元
订单总价324.00 元
定金97.20 元
尾款226.80 元
总成本79.00 元
利润245.00 元

运费与成本的填写提醒

「运费」会同时计入客户应付金额和你的成本，适合收取运费与实际寄件费用相同的情况。

如果给客户包邮，将「运费」填为 0，把自己支付的寄件费用填入「其他成本」。

如果加急服务产生额外支出，也应计入「其他成本」。同一笔支出不要重复填写。

成本超过总价时，利润会显示为负数。

七、更新订单状态

订单有六种状态：

状态使用时机
待付款客户尚未付款
已付定金已确认收到约定定金
制作中已收到约定定金，正在制作或处理
待收尾款等待客户支付剩余尾款
已完成已收齐款项，订单交付完成
已取消订单取消，保留记录供以后查询

推荐流程：

待付款 → 已付定金 → 制作中 → 待收尾款 → 已完成

更新方法：

  1. 打开「订单记录」。
  2. 找到订单，点击「详情」。
  3. 在「更新状态」中选择新状态。
  4. 点击「保存状态」。

也可以在「修改订单」中调整状态，再点击「保存修改」。

请注意：

  • 「制作中」按已收定金计算剩余应收。
  • 「已完成」按已收全款计算。
  • 制作结束但尾款未到账时，请使用「待收尾款」。
  • 「已取消」不计入待收款和首页总利润。

请先在实际收款平台确认到账，再更新状态。软件根据你选择的状态统计收款，不会自动核验到账。

八、搜索、修改和删除订单

搜索订单

打开「订单记录」，在搜索框输入客户昵称、项目名称或备注关键词。

可以同时使用状态筛选。例如输入“小林”，再选择「待收尾款」，查看该客户尚未结清的订单。

查看详情

点击「详情」，查看客户信息、费用、定金、尾款、成本和利润。

订单详情包含内部经营数据。给客户发送价格时，请使用报价单。

修改订单

  1. 打开订单详情。
  2. 点击「修改订单」。
  3. 调整信息，核对计算结果。
  4. 点击「保存修改」。

修改后，订单列表、客户历史和首页统计会同步变化。

如果客户已支付定金，再修改总价或定金比例，软件会重新计算约定金额。请另外核对已经实际收到的款项。

删除订单

在订单详情中点击「删除订单」，确认后删除。

删除后，订单记录、客户历史和首页统计会同步更新。

删除没有回收站，建议删除前先备份。需要保留交易记录时，可以改为「已取消」。

九、查看老客户的历史报价

打开「客户历史」，搜索客户昵称，即可查看该客户以前的订单，包括项目、单价、数量、总价、优惠和状态。

点击某笔订单的「详情」，可以查看完整内容。

客户再次下单时，点击「再次开单」。软件会带入客户昵称和联系方式，再由你填写本次项目和价格。

「再次开单」不会自动复制上一次的价格，请参考历史记录后确认本次报价。

同一位客户请尽量使用一致的昵称。遇到重名客户，可以加上平台或其他识别信息，例如“小林·微信”“小林·闲鱼”。

历史报价以当前保存的订单为准，修改旧订单后，历史内容也会更新。

十、生成并发送报价单

保存订单后，在订单列表点击「报价单」，或在详情中点击「生成报价单」。

报价单包含：

客户昵称、项目名称、数量、单价、商品金额、优惠、运费、加急费、其他费用、总价、定金、尾款和备注。

报价单不显示成本、利润和联系方式。

保存图片

  1. 打开报价单。
  2. 点击「保存图片」。
  3. 在浏览器下载文件夹中找到报价图片。
  4. 核对金额和备注后，发送给客户。

打印或保存 PDF

  1. 点击「打印 / 导出 PDF」。
  2. 在打印窗口中选择打印机，或选择「另存为 PDF」。
  3. 查看预览后打印或保存。

建议关闭打印设置中的「页眉和页脚」，让报价单更整洁。

订单修改后，请重新生成报价单。以前保存的图片和 PDF 不会自动更新。

十一、导出订单表格

需要用 Excel 或 WPS 整理账目时：

  1. 打开「备份与导出」。
  2. 点击「导出订单 CSV」。
  3. 找到下载的 .csv 文件。
  4. 用 Excel 或 WPS 打开。

导出包含全部订单，也包含已取消订单，不受当前搜索和筛选影响。

表格含联系方式、成本和利润，请自行保管。给客户报价时，请发送报价图片或 PDF。

如果表格乱码或内容挤在一列，请使用表格软件的「从文本 / CSV 导入」，编码选择 UTF-8，分隔符选择逗号。

CSV 用于查看账目，不能用于恢复软件数据。

十二、备份与恢复数据

数据保存在哪里

订单和价格库保存在当前电脑、当前浏览器中。正常关闭后，再从原位置用同一浏览器打开，可以继续查看。

订单不会写进 HTML 文件。只复制软件文件到另一台电脑，不会带走你的订单。

清理浏览器数据、更换设备或更换浏览器，可能使原来的记录无法显示。请定期备份。

导出备份

  1. 打开「备份与导出」。
  2. 点击「导出备份文件」。
  3. 找到下载的 .json 文件。
  4. 将文件保存到备份文件夹、百度网盘或移动硬盘。

备份包含全部订单和价格库。建议每天收工后备份一次，并保留不同日期的文件。

软件提示已导出后，请确认文件确实下载成功。

恢复备份

  1. 如果当前已有订单，先备份当前数据。
  2. 点击「选择备份文件」。
  3. 选择之前导出的 .json 文件。
  4. 核对显示的订单和价格库数量。
  5. 点击「确认恢复」。

恢复会替换当前全部订单和价格库，不会把两份数据合并。

如果选错备份并完成恢复，可以在「备份与导出」中下载「上一次导入前的恢复副本」，再导入该副本。

恢复副本只保留最近一次导入前的数据，不能代替定期备份。

换电脑或浏览器

在原来的软件中导出备份，把备份文件传到新电脑，再打开软件导入即可。

十三、常见问题

为什么换浏览器后看不到订单？

不同浏览器分别保存数据。请回原浏览器导出备份，再到新浏览器导入。

为什么新订单有利润，首页总利润却没有增加？

首页只累计「已完成」订单的利润。

为什么定金和预期不同？

检查定金比例是否填写正确。30% 应填写 30，还要确认费用和优惠是否正确。

为什么利润偏高？

检查单位成本和其他成本是否漏填。软件只计算已经录入的支出。

为什么客户历史没有合在一起？

客户按昵称归组，请检查前后昵称是否一致。

为什么改了价格库，旧订单没有变？

旧订单保留原来的报价。需要调整时，请单独修改订单。

保存失败怎么办？

先备份已有数据，再检查设备空间和浏览器设置。没有保存成功的订单，请不要当作已经记录。

删除后还能找回吗？

可以用包含该订单的旧备份恢复，但恢复会整体替换当前数据。
