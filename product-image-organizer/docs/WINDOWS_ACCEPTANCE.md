# Windows 发售前验收

自动测试负责图像逻辑、原图保护、界面事件循环和 Windows 打包启动；以下检查覆盖系统文件选择器、文件管理器及真实桌面交互。

在 Windows 10 和 Windows 11 各执行一遍：

1. 使用普通用户账号安装 Setup.exe，检查桌面快捷方式、程序名称、图标与中文安装界面。
2. 断开网络，拖入图片和带子文件夹的文件夹；检查可导入 JPG、PNG、WebP。
3. 使用 1、10、100、500 张图片整理，检查进度持续更新，窗口可移动，取消可用。
4. 用横图、竖图、透明 PNG 分别检查白底补齐、居中裁切和 JPG 转换。
5. 导入同内容不同名称、压缩或缩放的图，检查检测列表、二次确认、取消不生效。
6. 加一张损坏图片，确认其他图片仍能成功，并显示可理解的失败原因。
7. 输出到中文含空格路径，检查结果命名、报告及「打开输出文件夹」。
8. 在源目录作为保存位置操作，确认只新建结果文件夹，源文件哈希不变。
9. 切换浅色、深色、跟随系统，关闭再打开，检查设置记忆；再关闭记忆验证。
10. 检查 100% / 150% / 200% 显示缩放、1366×768 与较大屏幕。
11. 卸载软件，确认原图和整理结果仍保留。

第一版未签名，系统可能显示未知发布者。这一点应在销售说明中清楚告知；签名证书由发布者提供。
