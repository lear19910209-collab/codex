## 测试中已修复

- 非法设置可能阻止软件启动：改为恢复默认设置，并增加回归测试。
- CMYK 图转换后附带原有色彩描述可能出错：有效 ICC 转到 sRGB，失效 ICC 忽略，并增加回归测试。
- 缩略图的第三行文件大小被默认列表绘制截断：使用明确的三行卡片绘制，检查截图。
- 整理选项高度使格式下拉框被遮住：压缩卡片间距，并保留小屏滚动。

## Windows 构建验证

仓库根目录 `.github/workflows/product-image-windows.yml` 自动执行：

2. 运行相同的 65 项测试。
3. 使用 PyInstaller 创建 Windows 目录式 exe 与免安装 ZIP。
4. 检查打包程序主窗口正确出现且可正常退出。
5. 使用 Inno Setup 创建简体中文安装包。
6. 静默安装，检查安装后的程序启动、退出与卸载。
7. 只在全部成功后提供安装包、免安装包和 SHA-256 校验文件。

具体本次构建结果以 GitHub Actions 页面为准，最终交付说明会列出已执行结果。本地 Linux exe 不能当作 Windows exe。没有把仅写好配置等同于 Windows 构建已经成功。

## 已知限制

相似检测是启发式的，可能漏报或误报。PNG 压缩不会保证一定减小体积。动态 / 多帧图片暂不支持。单张最多 8000 万像素；取消要等待当前图片完成。安装包未签名。

真实 Windows 10 / 11 的拖放、文件选择器、Explorer 打开、高 DPI 和不同权限账号仍需按 [Windows 验收清单](WINDOWS_ACCEPTANCE.md) 最终验证。自动构建运行器不是消费者真实桌面，不能宣称已经完整完成买家电脑的人工验收。
